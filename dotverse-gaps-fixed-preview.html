FIX 3 · CRITICAL
prefers-reduced-motion Support
Zero @media (prefers-reduced-motion) rules existed across 11,927 lines. The ticker tape, pulsing session dots, signal scan-line, and spinner all ran continuously for users with motion sensitivity settings enabled at the OS level.
ADDED — covers all animation sources
@media (prefers-reduced-motion: reduce) {
  .tape-track    { animation: none; }
  .sess-dot .dot { animation: none; }
  .sig-hero::after { animation: none; }
  .rb-spin       { animation: none; }
  * {
    animation-duration:  .01ms !important;
    transition-duration: .01ms !important;
  }
}
Enable "Reduce motion" in your OS accessibility settings to verify. All animations halt instantly.
