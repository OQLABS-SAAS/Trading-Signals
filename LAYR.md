# LAYR Design System Rules

## Core Principles
- **No Slop:** Avoid generic, bubbly, or "over-designed" AI interfaces.
- **High Information Density:** Focus on data clarity. Use tight spacing and clear grids.
- **Minimalism:** Use system fonts and limited color palettes.

## UI Components
- **Borders:** Use 1px solid dividers. Avoid heavy shadows.
- **Corners:** Keep border-radius low (2px - 4px) for a professional, sharp look.
- **Spacing:** Use a strict 8px grid system.
- **Tables:** Clean headers, no zebra stripes, high-contrast text.

## Instructions for Claude
- When generating React, HTML, or Tailwind code, strictly adhere to these visual constraints.
- Prioritize functionality and readability for data-heavy applications (like trading dashboards).
